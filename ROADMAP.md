## Сводка проекта

PLG Voice — gaming-мессенджер, конкурент Discord/Telegram/Guilded. 17 Docker-сервисов, 57.8K LOC клиент, 2.8K LOC бот, 70+ локалей (активно: en/ru, 98.9% покрытие). Все основные функции реализованы: голос с Krisp, скрин-шеринг, видео, форумы, XP/уровни, турниры, автомод, premium, стикеры. Guilded закрылся — мы забираем их аудиторию и фичи.

## P1 — ВАЖНО (следующий спринт)

### 4. Защита данных: архив + шифрование + сжатие сообщений

> **Почему P1:** Сообщения в plain text в MongoDB. Файлы уже шифруются AES-256-GCM, а сообщения — нет. Удалённые сообщения уничтожаются навсегда без возможности восстановления. Для gaming-платформы это риск (GDPR, модерация, жалобы).

#### 4.1 Архив удалённых сообщений (soft delete)
**Затронутые файлы (Rust backend):**
- `server/crates/core/database/src/models/messages/model.rs` — `delete()` → `archive_message()` + `delete_message()`
- `server/crates/core/database/src/drivers/mongodb/messages.rs` — новый метод `archive_message()`

**Задачи:**
- [ ] Создать коллекцию `messages_archive` в MongoDB
- [ ] TTL-индекс на `deleted_at` с expireAfterSeconds = 94608000 (3 года)
- [ ] Изменить `delete()`: копировать в архив + добавить `deleted_at`, `deleted_by`
- [ ] Изменить `delete_bulk_messages()` аналогично
- [ ] Admin API: `GET /admin/archive?channel=X&before=DATE`
- [ ] Admin API: `POST /admin/archive/:id/restore`
- [ ] Миграция: создание коллекции + индекса

#### 4.2 Шифрование сообщений (Encryption at Rest)
**Затронутые файлы (Rust backend):**
- `server/crates/core/database/src/models/messages/` — encrypt на write, decrypt на read
- `server/crates/core/config/src/lib.rs` — секция `[messages]` с ключом
- `Revolt.toml.template` — `[messages] encryption_key`

**Задачи:**
- [ ] Модуль шифрования: AES-256-GCM, nonce (12 bytes) prefix
- [ ] Интеграция в write path: `create_message()`, `edit_message()`
- [ ] Интеграция в read path: `get_message()`, `get_messages()`, `search()`
- [ ] Миграция существующих сообщений (encrypt in-place, batch по 1000)
- [ ] Адаптация поиска: blind index (HMAC-SHA256 по словам) или отдельный поисковый индекс
- [ ] Шифрование архивных сообщений тоже

**Ограничения:**
- Поиск по зашифрованным сообщениям невозможен без дополнительного индекса
- Варианты: blind index (HMAC), MongoDB CSFLE (Enterprise), или поисковый индекс отдельно
- Blind index — самый реалистичный для open-source

#### 4.3 Сжатие сообщений
**Описание:** Порядок pipeline: `content → compress → encrypt → store`

**Задачи:**
- [ ] Модуль сжатия: zstd level 3 (2-4x выигрыш на тексте)
- [ ] Порог: только сообщения > 100 байт (короткие не сжимать — overhead)
- [ ] Флаг `compressed: bool` в документе для обратной совместимости
- [ ] Чтение: `store → decrypt → decompress → content`

**Порядок:** Архив (4.1) → Шифрование (4.2) → Сжатие (4.3)

### 5. Разбиение крупных компонентов

> **Почему P1:** TextEditor.tsx (1053 LOC) и Messages.tsx (1026 LOC) — это монолиты. Ошибка в одном месте крашит весь блок. Рефакторинг улучшит maintainability и снизит риск регрессий.

| Компонент | LOC | Выделить | Приоритет |
|-----------|-----|----------|-----------|
| `TextEditor.tsx` | 1053 | `AutoComplete.tsx`, `PlaceholderHandler.tsx`, `EditorToolbar.tsx` | Высокий |
| `Messages.tsx` | 1026 | `MessageFetcher.tsx`, `MessageRenderer.tsx`, `MessageGroup.tsx` | Высокий |
| `ServerSidebar.tsx` | 590 | `CategoryList.tsx`, `ChannelItem.tsx` | Средний |
| `ChannelPermissionsEditor.tsx` | 580 | `PermissionRow.tsx`, `RoleSelector.tsx` | Низкий |

**Правила:**
- Каждый рефакторинг — отдельный коммит с проверкой
- Не менять публичное API компонентов
- Выделять только логически самостоятельные блоки
- E2E проверка после каждого разбиения

### 10. Расширенный поиск (фильтры)

**Текущее состояние клиента:** фильтр-чипы уже реализованы (from/has/pinned/before/after), но бэкенд их игнорирует.

**Задачи:**
- [ ] Бэкенд: добавить параметры `author_id`, `has_attachment`, `has_embed` в search API
- [ ] Бэкенд: фильтрация по каналу (`channel_id`) в search
- [ ] Клиент: маппинг чипов на новые API параметры
- [ ] Автодополнение: при вводе `от:` → список пользователей

## Известные проблемы и ограничения

| Проблема | Описание | Workaround |
|----------|----------|------------|
| Webhook PATCH/DELETE 404 | API v0.11.1 не поддерживает | Только create/list |
| FILES_ENCRYPTION_KEY | НЕЛЬЗЯ менять/удалять — файлы невосстановимы | Бэкап ключа |
| WebSocket reconnect loop | nginx `proxy_send_timeout` нужно 86400s | Настроен |
| lingui hash IDs | Нужен extract после новых компонентов | `pnpm lingui:extract` |
| LiveKit NAT | `use_external_ip: true` обязательно | Настроен |
| Giphy rate limit | 42 запроса/час на бесплатном плане | Кеш в Redis |
