## 1. Главный урок: почему первый заход провалился

Первые двенадцать коммитов меняли **токены** — палитру, тени, тайминги,
радиусы, состояния наведения. Владелец продукта посмотрел на прод и сказал:
«визуально изменился цвет и несколько иконок, каркас не изменился». Он был
прав.

Конкретная причина была не в объёме работы, а в одной ошибке адресации:

```css
/* Было написано так — и не сработало нигде */
h1, h2, h3, h4, h5, h6 { font-family: var(--pd-font-display); }
```

**В этом приложении почти нет h-тегов.** Каждый заголовок настроек, имя
канала, шапка модалки — это `<span>`, который порождает рецепт
`typography` в `client/packages/client/components/ui/components/design/Text.tsx`.
Правило не достало ни до чего, что видит пользователь. Фирменный шрифт
проявился только на лендинге, где он был прописан руками.

### Правило, которое из этого следует

> Прежде чем менять стиль, найди место, где приложение **реально рендерит**
> этот элемент, а не место, где стиль логично было бы определить.

Проверка занимает минуту:

```bash
# Как на самом деле рендерится заголовок страницы настроек?
grep -rn "Text class=\"title\"\|typography({" --include=*.tsx components/app/interface/settings/
```

Если правка ушла в глобальный CSS или в токен, а компонент рендерится через
рецепт/cva — правка проиграет. Panda: `compoundVariants` перебивают
`variants`. Именно так стоковые значения Material тихо выигрывали.

## 4. Законы палитры — нарушать нельзя

Эти правила не косметические, они несут смысл. Их уже нарушали, и каждый раз
это давало конкретную поломку.

**Красный `#E00A45` — только то, что можно нажать.** Кнопки, активный
маршрут, акцентные метки.

**Нефрит `--pd-live: #00C48C` — только то, что в эфире.** Говорящий участник,
подключённый голос, открытый микрофон.

> В голосовом приложении «человек говорит» и «на это можно нажать» не имеют
> права быть одним цветом — иначе комната с говорящими читается как комната с
> кнопками. До этой ветки индикатор говорящего рисовался акцентом.

**Красный ≠ ошибка.** `--md-sys-color-error` остаётся для настоящих сбоев.
Непрочитанное, закреплённое сообщение, входящая заявка в друзья — это не
ошибки, они на акценте.

**Синий — минимальный канал во всех нейтралях.** Оболочка тёплая. Проверка:

```bash
# Любой нейтральный оттенок должен давать R >= G >= B
grep -A20 'if (darkMode)' client/packages/client/components/ui/themes/materialTheme.ts
```

Лаванда в нейтралях — это и был источник «стало светло-красное»: акцент рядом
с холодным серым читается розовым.

**Ноль литеральных `rgba(255,255,255,…)` для состояний.** Белое по светлому —
белое. Использовать `--pd-tint-subtle / -hover / -active`, они замешаны от
цвета чернил и работают в обеих темах.

**Одна бесконечная анимация на всё приложение** — `.pd-meter`. Она отражает
реально длящийся процесс. Всё остальное анимируется по событию.

**Язык новых пользователей — русский.** Раньше брался из браузера. У
существующих сохранённая локаль не трогается.

## 6. Как проверить, что редизайн действительно применился

Не «собралось без ошибок», а вот это. Если хоть один пункт не выполняется —
правка не долетела до места рендера, см. раздел 1.

```js
// В консоли браузера на любом экране приложения
getComputedStyle(document.querySelector('button')).fontFamily
// → должно начинаться с Bahnschrift / DIN Condensed, НЕ Inter/Roboto

getComputedStyle(document.querySelector('button')).textTransform
// → uppercase

getComputedStyle(document.documentElement).getPropertyValue('--pd-surface-raised')
// → непустое; на светлой теме разрешается в белый
```

Глазами:

- Активный канал в сайдбаре — приподнятая светлая плашка с красной полосой
  слева, **не** заливка акцентом.
- Говорящий участник — нефритовый, **не** красный.
- Ни одной кнопки-пилюли с белым бликом внутри.
- Заголовки настроек и имена каналов — узкой гарнитурой.
- Переключить светлую/тёмную: обе живые, `[data-mode]` на `<html>`
  переключает `--pd-surface-raised` и `--pd-live-ink`.

## 7. Открытые дефекты

**`og:image` отдаёт 404.** `og-preview.png` отсутствует в сабмодуле `assets`
целиком — он есть только в `client/packages/client/scripts/assets_fallback/`,
который подключается лишь когда сабмодуль пуст. `index.html` ссылается на
`/assets/web/og-preview.png`. Превью ссылок в мессенджерах пустые, и так было
до этой ветки. Макет в «Полдне» готов рядом в `.svg` — нужен растеризатор
(`rsvg-convert`, `sharp`, Inkscape), 1200×630.

**Размер бандла.** Главный чанк ~3 000 кБ при ориентире < 1 500 кБ из
роадмапа. Владелец этого не заказывал.

**153 литеральных `fontSize`** в px по коду. Консистентность, не поломка.
Лендинг и `/app` самодостаточны намеренно.

## 8. Порядок работы, которого ждёт владелец

- Сначала план, потом код.
- Маленькие диффы: один экран → проверка → следующий.
- Не объявлять сделанным то, что не проверено глазами на реальном экране.
  Это самая частая претензия к предыдущему агенту, и она справедлива.
- Скриншот убеждает быстрее описания.
