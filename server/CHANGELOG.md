# Changelog

All notable changes to the PLG Voice backend will be documented in this file.

## 0.11.5 (2026-02-17)

- Initial PLG Voice backend release based on forked upstream code
- Voice chats v2 with LiveKit integration
- File encryption support
- Webhook support
- RabbitMQ message bus
- Push notification daemon
- Tenor GIF proxy (gifbox)
- Rate limiting improvements
- Bug fixes and stability improvements
