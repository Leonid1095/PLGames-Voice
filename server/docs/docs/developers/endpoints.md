# Endpoints

You can connect to the API on the following URL:

| URL                              |  Release   | Description          |
| -------------------------------- | :--------: | -------------------- |
| `https://plgames-voice.ru/api`   | Production | Primary API endpoint |

You can connect to the events server on the following URL:

| URL                                |  Release   | Description             |
| ---------------------------------- | :--------: | ----------------------- |
| `wss://plgames-voice.ru/events`    | Production | Primary events endpoint |
