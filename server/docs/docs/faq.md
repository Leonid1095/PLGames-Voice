# Frequently Asked Questions

This page includes several frequently asked questions about PLG Voice.

<details>
  <summary>What is PLG Voice?</summary>

  PLG Voice is a voice and text messenger platform built by PLG Games. It supports text channels, voice channels with LiveKit, file sharing, and more.
</details>

<details>
  <summary>How do I self-host?</summary>

  PLG Voice can be self-hosted using Docker Compose. See the main project README for setup instructions.
</details>

<details>
  <summary>What license is PLG Voice under?</summary>

  The backend is licensed under AGPLv3. Individual core crates may have MIT licenses. See the LICENSE file for details.
</details>
